
# Student Budget Tracker

Student Budget Tracker — это простой инструмент для персонального учёта личных финансов в период обучения. Проект помогает фиксировать регулярные поступления средств, контролировать повседневные траты и заранее планировать накопления. С его помощью студент может избежать кассовых разрывов и рационально распределять стипендию и заработок.

## Статьи доходов и расходов

### Источники поступлений (доходы)
* Академическая и повышенная стипендия
* Финансовая помощь от родителей
* Подработка или фриланс
* Разовые выплаты и кешбэк

### Категории трат (расходы)
* Проживание (общежитие / аренда комнаты, коммунальные услуги)
* Питание и бытовая химия
* Транспортные расходы (проездной билет)
* Учебные материалы и канцелярия
* Развлечения, отдых и подписки

## Таблица ежемесячного бюджета

## Алгоритм расчёта остатка

Для корректного подведения итогов месяца выполните следующие шаги:

1. Вычислите суммарный объём всех фактических доходов за месяц.
2. Подсчитайте общую сумму всех совершённых расходов.
3. Вычтите итоговые расходы из полученных доходов для определения свободного остатка.
4. При наличии положительного баланса переведите не менее 10% в резервный фонд.

### Пример расчёта (Python)

```python
def calculate_balance(incomes: list[float], expenses: list[float]) -> float:
    total_income = sum(incomes)
    total_expense = sum(expenses)
    balance = total_income - total_expense
    return balance

# Пример за месяц
incomes = [4500.0, 22000.0]
expenses = [11500.0, 1500.0, 1600.0, 600.0]

remainder = calculate_balance(incomes, expenses)
print(f"Итоговый остаток на конец месяца: {remainder:.2f} руб.")
